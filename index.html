How production Gmail actually works (for the operator)
  1. Create a Google Cloud project and enable the Gmail API.
  2. Create an OAuth 2.0 client (Web application) and add the production redirect URI.
  3. Request scopes gmail.readonly and gmail.compose only.
  4. Store the client ID and secret on the server — never in this page.
  5. BotLancer creates a draft for every enquiry. A human must press send.

Full steps ship in CONNECT.md with this build.
